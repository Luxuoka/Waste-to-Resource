## 📖 Tentang Proyek

**Waste-to-Resource** adalah website edukasi daur ulang yang mengajak generasi muda mengubah sampah plastik, kertas/kardus, dan kaleng menjadi produk bernilai guna. Pengguna bisa belajar lewat tutorial video, mencari inspirasi karya, dan menemukan lokasi pengolahan sampah terdekat di Kota Bandung.

| | |
|---|---|
| 🎯 **Tujuan Utama** | Memfasilitasi siswa belajar mengolah sampah anorganik secara mandiri. |
| 👥 **Target Pengguna** | Siswa/i SMA dan Generasi Z (15-18 tahun) yang peduli kebersihan lingkungan. |
| 📱 **Mobile-Friendly** | Antarmuka nyaman dan responsif diakses lewat smartphone kapan saja. |
| 🌿 **Ramah Lingkungan** | Mendukung pengurangan sampah di TPA melalui aksi nyata daur ulang dari sumbernya. |

## ✨ Fitur Utama

| | Halaman | Deskripsi |

| 🏠 | **Beranda** | Pengenalan program, statistik (17+ DIY visual, 24+ inspirasi, 5+ lokasi daur ulang), panduan jenis sampah, dan alur 3 langkah mengolah sampah. |

## ♻️ Alur 3 Langkah Mengolah Sampah

```
1. Pilah dari Sumber  →  2. Bersihkan & Keringkan  →  3. Olah atau Setor ke TPST
```

1. **Pilah dari Sumber:** pisahkan sampah anorganik (plastik, kertas, kaleng) sejak awal agar tetap bersih dan bernilai.
2. **Bersihkan & Keringkan:** bilas sisa cairan atau kotoran, lalu tiriskan hingga kering agar higienis saat diolah.
3. **Olah atau Setor ke TPST:** kreasikan menjadi produk bernilai guna lewat tutorial video, atau salurkan ke TPST terdekat.

## 🗺️ Lokasi TPST di Kota Bandung

| Lokasi | Keterangan |
|---|---|

| **TPST Tegallega** | Modern & RDF |
| **TPST Batununggal** | Kompos & RDF |
| **TPST Nyengseret** | Pengolahan sampah terpadu |

> RDF (*Refuse-Derived Fuel*) adalah bahan bakar alternatif yang dihasilkan dari pengolahan sampah.
